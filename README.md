# 居民楼屋顶光伏认购发电结算与维修平台

面向社区分布式光伏（以楼栋为单位）的全周期管理平台：**立项评估 → 楼栋表决 → 认购缴费 → 施工排期 → 并网验收 → 发电计量 → 月度收益结算 → 长期运维与房屋转让**，把住户认购份额、公共账户、补贴、发电量、电价、维修基金、退款机制和责任边界连成一本清楚的账。

技术栈：React 18 + Vite（前端）／ Go 1.19 + 标准库 net/http + lib/pq（后端）／ PostgreSQL 15（数据库）。Go 二进制同时托管前端构建产物，**一个应用容器 + 一个数据库容器即可运行**。

## 一、一键启动（Docker Compose）

```bash
docker compose up --build
```

- 应用：http://localhost:8080 （前端页面 + API 同源）
- 首次启动自动建表并写入演示楼栋/住户数据（`AUTO_MIGRATE=true`）
- 停止并清空数据：`docker compose down -v`

## 二、本地开发启动

### 1. 准备数据库

```bash
# 方式一:本机已装 PostgreSQL
createdb rooftoppv
# 方式二:仅启动数据库容器
docker run -d --name pv-pg -e POSTGRES_USER=pv -e POSTGRES_PASSWORD=pv123 \
  -e POSTGRES_DB=rooftoppv -p 5432:5432 postgres:15-alpine
```

### 2. 后端（默认 :8080）

```bash
cd backend
export DATABASE_URL="postgres://pv:pv123@localhost:5432/rooftoppv?sslmode=disable"
go run . migrate          # 建表 + 种子数据(可重复执行)
go run .                  # 启动 API
```

### 3. 前端（开发热更新，:5173，自动代理 /api → :8080）

```bash
cd frontend
npm install
npm run dev
```

前端构建后也可由 Go 直接托管：

```bash
cd frontend && npm run build
cd ../backend
FRONTEND_DIST=../frontend/dist go run .   # 打开 http://localhost:8080
```

## 四、推荐验证路径（覆盖全部业务闭环）

用**管理员/物业**与**住户**账号交替操作：

1. **立项评估**：楼栋概览查看屋顶面积、朝向、承重、遮挡、产权、公共收益规则、并网条件、施工影响。
2. **楼栋表决**：≥9 户住户登录投票赞成（户数与产权面积双 67% 门槛，可实时看计票）；顶楼住户可填"担心漏水"意见。管理员「推进到下一阶段」，未达标时后端拒绝推进。
3. **认购缴费**：住户认购组件（如 20 块）或选"只参与公共收益分配"；在线缴费；有人未缴时无法进入施工排期。
4. **施工排期**：登记"组件供应延迟 2 周""电网并网时间提前"等事件留痕；登记 2 台逆变器（组件 1–100、101–200）。
5. **并网验收与计量**：推进阶段后按月录入各逆变器发电量，录入后自动进入发电运营；对偏低月份发布"发电异常解释"。
6. **维修与责任**：住户报修逆变器故障/顶楼漏水；物业处理时判定责任方（供应商/施工方/物业/住户/公共）、维修费、影响周期、少发电量与赔偿比例——赔偿额 = 少发电量 ×（电价+补贴）× 比例。
7. **月度结算**：生成月度草稿（自动汇总电量、收入、补贴、运维费、税费、维修基金、维修支出与责任赔偿，按认购组件比例出住户明细与公共部分）→ 核对后「确认入账」：公共账户记流水、住户收益发放生成流水，**已确认结算不可重算**。
8. **公共账户**：查看余额与逐笔流水（结算入账、补贴、赔偿、运维、税费、维修、收益发放、退款）。
9. **房屋转让**：登记某住户卖房，选择①认购权益随房转移（原账号停用、新业主密码重置为 123456）或②不转移退本金（公共账户出账、认购置为已退款），并确认历史收益是否结清。
10. **异议投票**：住户就收益测算/通道问题提出异议 → 物业发起投票 → 全体住户投票 → 裁决异议是否成立。
11. **年度报告**：查看年度收入/公共支出/维修记录、月度图表、住户收益榜、碳减排（0.581 kgCO₂/kWh）、节约标煤与等效植树。

## 五、关键计算口径

- 发电收入 = 实际发电量 × 结算电价；补贴 = 发电量 × 度电补贴
- 可分配净额 = 发电收入 + 补贴 + 责任方赔偿 − 运维费 − 税费 − 维修基金计提
- 住户分配 = 净额 ×（1 − 公共部分比例）×（本人已缴费认购组件数 / 总组件数）；其余归公共账户
- 维修联动：指定了影响周期且已处理的工单，其赔偿/支出自动进入该周期结算草稿
- 维修基金按毛收益比例逐月计提，留存于公共账户专款专用
